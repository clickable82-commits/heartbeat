# 하트비트

주변 AED(자동심장충격기)를 찾고, 심정지 상황에 대응하는 흐름을 보여 주는 **시연용** 앱입니다.

## 기능

- **현재 위치 추적** · 휴대폰 GPS로 내 위치를 따라갑니다. 위치를 못 쓰면 화면에 «위치 켜기»가 뜹니다.
- **공공 AED 위치** · 전국 공공 AED 61,649곳을 지도에 표시하고, 가장 가까운 곳을 알려 줍니다.
- **새 AED 등록** · 등록하면 지도에 바로 나타납니다.
- **심정지 알림** · 주변 사용자에게 보내는 알림을 휴대폰 알림으로 보여 줍니다.
- **119 자동 신고** · 10초 카운트다운 뒤 신고 화면을 보여 줍니다. **실제로 신고되지 않는 시연 화면입니다.**

## 실행 방법

필요한 것: 컴퓨터에 [Node.js](https://nodejs.org) (LTS), 휴대폰에 **Expo Go** 앱. 컴퓨터와 휴대폰은 같은 와이파이에 연결합니다.

```bash
npm install
npx expo start
```

화면에 뜬 QR 코드를 휴대폰으로 찍습니다 (안드로이드는 Expo Go 앱 안에서, 아이폰은 기본 카메라로).
처음 열 때 위치 권한을 «허용»해야 현재 위치가 뜹니다.

## 데이터 출처

- 공공 AED 위치: 공공데이터포털 「전국 자동심장충격기 표준데이터」
  `scripts/build-public-aeds.js`로 앱에 넣을 크기로 줄였습니다 (이동형 · 구급차 AED 제외).
- 지도: 안드로이드는 OpenStreetMap(Leaflet), iOS는 기본 지도.

## 만든 기술

Expo (React Native) · expo-router · expo-location · expo-notifications
